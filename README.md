### Backend
1. Navigate to `SalesOrderBackend/SalesOrderAPI`.
2. Run `dotnet run`.
3. The API will be available at `http://localhost:5262`.

### Frontend
1. Navigate to `sales-app`.
2. Run `npm install` (if dependencies are not present).
3. Run `npm start`.
4. The application will be available at `http://localhost:3000`.
